CLASS

Reference type · variables share one object

public class Order
{
public int Id { get; set; }
public string Status { get; set; } = "New";
}
 
var a = new Order { Id = 1 };
var b = a; // same object
b.Status = "Paid";
Console.WriteLine(a.Status); // Paid
HOW IT BEHAVES
Variable holds a reference to the object
Lives on the heap, freed by the GC
Can be null and supports inheritance
USE IT FOR Entities, services and shared state, like EF Core models. WATCH OUT b = a copies only the reference, not the object.
