Struct

STRUCT

Value type · every variable gets its own copy

public struct Point
{
public int X;
public int Y;
}
 
var a = new Point { X = 1, Y = 2 };
var b = a; // a copy
b.X = 99;
Console.WriteLine(a.X); // 1
HOW IT BEHAVES
Variable holds the value itself
Stored inline: on the stack or inside its owner
Cannot be null, no class inheritance
USE IT FOR Small values like points, money or dates. Keep it about 16 bytes or less. WATCH OUT Changing a copy never changes the original. Prefer readonly struct.
